# DMI CAD 0.4.0 — 화면 면 선택

## 목적·순서
1. DMI 솔리드를 만들거나 프로젝트를 엽니다.
2. 스케치 탭 → **화면 면 선택**을 누릅니다.
3. 모델의 평평한 면을 왼쪽 클릭합니다. 선택 면이 주황색으로 표시되고 상태줄에 면 번호·평면·위치·면적이 나옵니다.
4. 선택을 확인한 뒤 **선택면 스케치**를 누릅니다. 원 스케치가 시작되며, 평면/오프셋과 솔리드 안쪽 컷 방향을 설정합니다.
5. 좌표·반지름 → 스케치 치수 적용 → 스케치 종료 → 돌출 컷 → 깊이/관통 → 확인합니다.
6. 면 선택 중 Esc로 취소합니다. 빈 공간 클릭은 선택을 해제합니다. 가운데 버튼 회전·Ctrl+가운데 이동·휠 확대 조작은 유지합니다.
7. 사각형을 시작하거나 목록으로 면 위치를 고르려면 기존 **면에서 스케치**를 사용합니다.

선택은 앞에 보이는 면을 대상으로 합니다. 곡면이나 경사진 면을 클릭하면 미지원 안내를 표시합니다. 면 경계 근처에서는 픽셀 해상도에 따라 인접 면이 선택될 수 있으므로 확대하고 면 내부를 클릭하세요.
화면 선택은 자체 DMI 솔리드에만 제공합니다. 기존 교환 파일 뷰어에는 이번 기능이 연결되지 않았습니다.

## 정밀도와 한계
표시 메시의 각 삼각형은 원래 OCCT 면 번호와 함께 생성됩니다. 픽셀 선택은 이 대응을 사용하며 면 위치는 정밀 형상에서 가져옵니다. 면을 선택했다고 표시 메시 좌표를 정밀 측정값으로 사용하지 않습니다.
면 번호는 현재 재계산 결과에서만 유효합니다. 재계산/프로젝트 전환 시 선택을 지웁니다.
XY/XZ/YZ와 평행한 평면만 스케치에 사용할 수 있습니다. 선택면 스케치는 위치 복사이며 면에 연결된 참조가 아닙니다. 이전 치수를 수정해 면이 이동하면 스케치 오프셋도 직접 수정해야 합니다.
일반 스케치 구속 솔버·임의 평면·모서리/꼭짓점 선택·정밀 측정·도면/조립은 이번 업데이트에 포함되지 않습니다. 프로젝트 v3를 유지합니다.

## 검증
CI에서 정밀 면과 표시 삼각형의 번호/평면 일치, 곡면의 가림 데이터, 깊이별 가시성 선택·배경 선택·주황색 표시를 검사합니다. 실제 GUI에서 픽셀 선택 이벤트 → 면 스케치 → 관통 컷 → 저장 재읽기/재계산 → 취소를 검사하고 선택 화면을 캡처합니다.
자동 검사는 프로그램 내 마우스 이벤트 호출을 사용합니다. 실제 사용자 마우스·다중 DPI/화면·접근성 시험이나 SOLIDWORKS와의 완전 호환 시험은 아닙니다.
