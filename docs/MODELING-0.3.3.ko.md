# 디엠아이 CAD 0.3.3 — 중간 평면 돌출·컷

## 목적
기준면을 중심으로 양쪽에 같은 길이의 재료를 추가하거나 제거합니다. 중심을 유지하는 판·보스와 대칭 절삭 형상을 만들 때 사용합니다. **전체 깊이 20 mm는 양쪽 각각 10 mm**입니다.

## 사용 순서
1. 스케치 탭에서 사각형/원/닫힌 다각형을 만들고 치수를 적용한 뒤 스케치를 종료합니다.
2. 피처 → 돌출 보스/베이스 또는 돌출 컷을 선택합니다.
3. 왼쪽 속성에서 기준면과 평면 오프셋(mm)을 설정합니다. 오프셋은 양쪽 돌출의 중심 위치입니다.
4. 전체 깊이(mm)를 입력하고 **중간 평면**을 체크합니다. 반대 방향은 비활성화되며 중간 평면 형상에는 영향을 주지 않습니다.
5. ✓ 확인으로 정밀 솔리드를 계산합니다. 확인 전에는 기존 모델을 표시하며 실시간 형상 미리보기는 제공하지 않습니다.
6. 기존 피처는 트리에서 선택 → 우클릭 → 피처 정의 편집으로 변경합니다. 취소/Esc는 미확정 변경을 버리며 Ctrl+Z/Y는 확정한 모델 변경을 취소/다시 실행합니다.
7. 프로젝트 저장으로 설정을 보존합니다.

예: XY 평면, 오프셋0, 전체 깊이20이면 Z=-10~+10입니다. 오프셋5이면 Z=-5~+15입니다.
XZ에서는 Y, YZ에서는 X축 좌표가 중심 양쪽으로 변합니다.

중간 평면을 끄면 기존 한 방향 돌출로 돌아갑니다. 반대 방향의 저장값도 다시 적용되므로 체크 상태를 확인하세요.
컷이 재료와 만나지 않거나, 추가 돌출이 떨어진 별도 솔리드를 만들면 오류로 거부하고 기존 모델을 유지합니다. 평면·오프셋·깊이·방향을 수정하세요.

## 프로젝트 호환
0.3.3은 프로젝트 형식 **v2**로 저장합니다. 기존 v1 파일은 읽고 메모리에서 v2로 변환하며 원본은 저장 전까지 바꾸지 않습니다. v2 파일은 0.3.2 이하에서 열 수 없습니다. 오래된 앱이 중간 평면을 무시해 다른 형상으로 계산하는 일을 막기 위한 구분입니다. 기존 파일을 보존하려면 다른 이름으로 저장하세요.
정밀 형상 공유에는 STEP/IGES 출력도 사용할 수 있으나 DMI 피처 이력을 전달하지 않습니다.

## 범위와 검증
XY/XZ/YZ 기준면, 원·닫힌 다각형, 단일 솔리드의 일정 깊이 돌출/컷입니다. 양쪽 길이 개별 지정, 끝면 지정, 면에 붙이는 스케치, 일반 구속 솔버, 필렛, 도면·조립·금형·CAM은 미지원입니다.
CI에서 3평면의 중심 오프셋·전체 깊이·STEP 좌표 범위와 정확한 부피, 방향 반전 시 형상 불변, 원 돌출과 관통 컷, v1/v2 읽기·미지원 버전 거부, 실제 GUI 확인/취소/실행 취소/다시 실행을 검사합니다. 전체 수동 마우스·DPI·접근성 검증은 별도로 남아 있습니다.
