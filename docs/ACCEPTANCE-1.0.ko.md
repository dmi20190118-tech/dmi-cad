# DMI CAD 1.0 핵심 모델링 합격 기준

버전 번호만 변경하지 않습니다. 아래 작업을 실제 윈도우 프로그램에서 완료하고 형상·저장 복원 및 사용자 조작을 검증해야 1.0 핵심 모델링을 완료했다고 보고합니다.

|작업|0.3.4 구현 범위|남은 검증/개발|
|---|---|---|
|스케치|사각형·원·닫힌 다각형과 숫자 치수|호·기하/치수 구속 및 충돌 설명|
|돌출|기준면·오프셋·깊이·반전·중간 평면|폭넓은 고객 예제와 수동 조작|
|평면 정의|XY/XZ/YZ와 숫자 오프셋|제품 평면 선택 및 연결된 참조, 임의 평면|
|파기|지정 깊이·한 방향 관통|선택면 기반 전체 흐름, 추가 끝 조건|
|수정|피처 재계산·실행 취소/다시 실행|연결된 면 참조의 변경 추적|
|저장 복원|피처 이력·설정·재계산 자동 검사|환경별 복구·사용자 파일 검증|

필수 시나리오: 스케치 → 돌출 → 윗면 선택 → 구멍 스케치 → 관통 컷 → 원 치수/판 두께 수정 → 저장 → 종료 → 다시 열기. 형상 부피/구멍 크기를 정밀 엔진에서 검사하고 초보 사용자가 순서대로 수행하도록 수동 시험을 기록합니다.
0.3.4의 자동 시나리오는 숫자 기준면 오프셋을 사용합니다. 윗면 선택을 구현한 것으로 설명하지 않습니다.
도면·조립 및 장기 금형/CAM 목표도 별도 완료 기준이 필요합니다. 이 문서는 완성 또는 일정 보장이 아닙니다.
