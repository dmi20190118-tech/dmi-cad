# 디엠아이 CAD 0.3.2 — 돌출 방향
## 목적과 작업 순서
스케치 평면에서 반대 방향으로 재료를 추가하거나 제거합니다. 상단 평면에서 아래쪽으로 구멍을 가공하는 형상을 만들 때 유용합니다.
1. 스케치에서 사각형/원을 그리거나 좌표·치수를 적용하고 스케치를 종료합니다.
2. 피처 → 돌출 보스/베이스 또는 돌출 컷을 선택합니다.
3. 왼쪽 속성에서 평면, 오프셋, 깊이를 설정합니다. 깊이는 양수 mm입니다.
4. **반대 방향**을 체크하면 기본 방향을 뒤집습니다. ✓ 확인으로 실제 솔리드를 계산합니다.
5. 기존 피처는 트리에서 선택 → 우클릭 → 피처 정의 편집으로 방향을 수정합니다. 취소/Esc는 확정 전 변경을 버립니다. Ctrl+Z/Y로 확정한 작업을 취소/다시 실행합니다.
6. .dmipart 저장 및 다시 열기에서 방향을 보존합니다. 구버전 프로젝트에 방향값이 없으면 기존 기본 방향으로 읽습니다.

|평면|기본|반대 방향|
|---|---|---|
|XY|+Z|−Z|
|XZ|−Y|+Y|
|YZ|+X|−X|

예: XY 평면의 20×10×10 mm 판에서 중심(5,5), 반지름2 mm 원을 만들고, 컷의 오프셋10 mm·깊이10 mm·반대 방향을 설정하면 아래로 관통합니다.
방향을 잘못 설정해 솔리드와 만나지 않는 컷은 실패합니다. 평면·오프셋·방향을 확인하고 다시 적용하세요. 실패하면 기존 모델을 유지합니다.

## 범위 및 검증
단일 솔리드와 기준면 XY/XZ/YZ의 일정 깊이 돌출/컷에 한정합니다. 중간 평면, 양방향, 끝면 지정, 면 선택, 일반 스케치 구속, 필렛, 도면·조립·CAM은 이번 기능에 포함되지 않습니다.
0.3.1이 reverse 속성을 해석하지 않으므로, 이 버전의 프로젝트는 0.3.2 이상에서 열어야 방향이 보존됩니다. 프로젝트 형식 v1에 선택적 boolean reverse를 추가했습니다.
Windows CI에서 3평면 반전 돌출의 STEP 좌표 범위/부피, 위에서 아래로 관통 컷, 잘못된 방향 속성 거부, 방향 복사/직렬화, 실제 GUI 확인/취소/실행 취소/다시 실행을 검사합니다. 성공 여부는 해당 빌드 결과를 확인해야 합니다. 수동 전체 마우스·DPI 검증은 포함하지 않습니다.
