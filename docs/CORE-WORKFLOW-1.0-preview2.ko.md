# 기본 모델링 흐름 수정 — 1.0 개발판 2

## 수정한 문제
기존 도형 시작 함수가 원/사각형/선 도구를 바꿀 때 평면 연결·방향·편집 상태를 초기화했습니다. 면 선택에는 별도 선택 모드가 필요했고, 선택면 스케치는 원/잘라내기용으로 고정됐습니다. 이전 자동 검사도 숫자를 직접 넣는 경로가 중심이라 일반 작업 순서의 문제를 충분히 잡지 못했습니다.

## 이번 작업 순서
### 1. 기준면에서 첫 솔리드
1. 새 부품 → 왼쪽 기준면을 펼치고 XY/XZ/YZ 중 하나 선택.
2. 스케치 탭 → 사각형/원/선 도구.
3. 화면에 도형을 그립니다. 사각형은 대각 두 점, 원은 중심과 둘레 한 점, 선은 점들을 찍고 첫 점/다각형 닫기입니다.
4. 숫자로 정의하려면 좌표·치수를 입력하고 **치수 적용** 또는 Enter.
5. 스케치 종료 → 피처 → 돌출 보스/베이스 → 깊이 → 확인.

### 2. 제품 면에서 두 번째 돌출
1. 모델의 평평한 면을 **그냥 왼쪽 클릭**합니다. 별도 '화면 면 선택' 버튼을 먼저 누를 필요가 없습니다.
2. 주황색 선택 확인 → 스케치 탭의 사각형/원/선 도구를 선택합니다. 기존 선택면 스케치 버튼도 사용할 수 있습니다.
3. 도구를 바꿔도 선택 면·평면 연결이 유지됩니다. 스케치 화면에는 해당 면이 옅은 파란 배경으로 표시됩니다.
4. 도형 작성 → 스케치 종료 → 돌출 보스 → 깊이 → 확인. 선택 면의 바깥쪽이 기본 방향입니다.

### 3. 다시 면 선택 후 파기
1. 새 보스의 평평한 면 클릭 → 원/사각형 등 도구 → 도형 작성 → 스케치 종료.
2. 돌출 컷을 누르면 기본 방향이 솔리드 안쪽으로 전환됩니다.
3. 지정 깊이 또는 끝까지 관통 → 확인.
4. Ctrl+Z/Y와 저장/다시 열기로 형상 및 피처 이력을 유지합니다.

피처를 편집하려면 트리 우클릭 → 피처 정의 편집 또는 스케치 편집을 사용합니다. 스케치 편집 중 도형을 바꿔도 기존 피처를 편집하는 상태를 유지합니다.

## 선택과 스케치의 범위
- 면 선택/스케치는 XY/XZ/YZ와 평행한 평면만 지원합니다. 곡면/경사진 면은 아직 미지원입니다.
- 평면 면 배경은 표시 메시에서 가져온 시각 참조입니다. 경계에 대한 정밀 스냅/기하 구속이나 측정은 아닙니다.
- 면의 전역 기준면 좌표를 사용합니다. 모서리가 자동으로 원점이 되지 않습니다.
- 모호하지 않은 이전 한 방향 돌출 끝 평면만 연결합니다. 기타 평면은 고정 위치 복사입니다.
- 숫자 입력은 치수 적용/Enter로 도형에 반영합니다. 숫자만 바꾸고 적용하지 않은 값은 형상에 반영되지 않습니다.
- 기존 모델의 피처 속성 편집 중에는 화면 클릭으로 새 면 선택을 시작하지 않습니다. 확인/취소한 뒤 새 면을 고르세요.
- 이번 수정은 스케치 세션·평면·방향을 이어주는 문제를 고칩니다. 일반 구속 솔버·호·임의 면 스케치까지 완성한 것은 아닙니다.

## 검증 시나리오
숫자로 피처만 조립하지 않고 실제 SketchEditor의 마우스 입력 이벤트로 다음을 실행합니다.
1. XZ 평면 선택 후 도구 변경 시 평면 유지 검사.
2. XY에서60×40 사각형을 두 번 클릭으로 그림 → 깊이10 보스: 부피24000 mm³.
3. 보통 면 클릭 → 사각형에서 원으로 도구 변경 → 반지름5 원을 두 번 클릭으로 그림 → 깊이8 외측 보스.
4. 그 보스 윗면 클릭 → 원 그리기 → 내측 관통 컷(반지름2).
5. 각 단계의 정밀 부피 비교, 디스크 저장/재읽기/재계산, 실행 취소/다시 실행.
6. 기존 회전·필렛·평면 연결·파일 변환 검사도 유지합니다.

자동 검사는 운영체제 마우스 하드웨어가 아닌 컨트롤의 마우스 이벤트를 호출합니다. 사용자 PC에서의 실제 조작·전체 DPI/접근성 검증은 아직 별도입니다.
