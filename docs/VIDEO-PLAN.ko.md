# 사용자 교육 영상 구성안

상태: **영상 기획·대본 초안. 아직 실제 교육 영상 파일을 제작하지 않았다.**
실제 동작이 없는 기능은 완성된 제품 시연처럼 제작하지 않는다.

## 공통 촬영 기준
- 실제 배포 빌드와 공유 가능한 예제 파일을 사용한다.
- 시작 화면, 클릭/터치 위치, 입력 의미, 완료 결과를 순서대로 보여준다.
- 포인터·클릭·키 조합을 표시하고 한국어 자막을 제공한다.
- 빠른 편집으로 중요한 선택·확인 단계를 생략하지 않는다.
- 시작 또는 설명란에 버전·빌드·지원 범위·문서 링크를 표시한다.
- 실제 고객 모델·파일 경로·계정·도면 정보는 허락 없이 노출하지 않는다.
- 잘못 입력한 사례와 수정하는 과정도 포함한다.
- 실제 녹화 결과를 기준으로 대본을 고친다. 영상 제목만으로 기능 구현을 주장하지 않는다.

## 현재 기능으로 만들 영상

### A. 처음 실행하고 모델 확인하기 (약 3분)
1. 제목: 'DMI CAD 시제품 — 파일 열어보기'. 현재는 정밀 CAD가 아닌 초기 뷰어임을 안내.
2. 설치 후 화면의 상단 메뉴, 모델 트리, 작업 화면 소개.
3. 예제 STEP 선택 → 읽기 완료 → 파일명·형상 확인.
4. 가운데 버튼 회전, Ctrl+가운데 버튼 이동, 휠 확대, 가운데 버튼 더블클릭 맞춤.
5. 정면/평면/등각 변경.
6. 원본 단위·형상과 비교해야 한다는 점, 미지원 형식 안내.
7. 기대 결과: 예제 모델을 열고 여러 방향에서 확인한다.

### B. 가공 지시서 초안 만들기 (약 4분)
1. 상단 가공 지시서 메뉴를 연다.
2. 가상의 도면/공정/장비/소재/원점을 입력한다.
3. 공구 D=10, Z=4, S=3000, F=600 예시를 입력한다. 실제 권장 가공 조건이 아니라는 자막.
4. ap/ae, 치수·공차, 참조값·출처를 입력한다.
5. 입력 점검: 계산 Vc 약 94.248 m/min, fz=0.05 mm/tooth를 확인한다.
6. 참조 최대 회전수 6000에 S=7000을 넣어 경고를 재현한다.
7. 누락 입력도 재현한 뒤 수정한다.
8. 초안 저장·불러오기, 인쇄용 HTML, 브라우저 PDF 저장을 보여준다.
9. NC 자동 대조와 실제 Excel 양식 연결은 아직 없음을 안내한다.

### C. 아이폰에서 웹 체험하기 (약 2분)
1. Safari에서 모바일 체험판 주소를 연다.
2. 조건 입력 → 입력 점검 → 시트 보기 순서로 조작한다.
3. 예시 숫자를 잘못 넣고 메시지를 확인한다.
4. 3D 체험: 한 손가락 회전, 두 손가락 이동/확대, 치수 변경.
5. 시트와 예제 입체 치수는 연동되지 않으며 CAD/NC 엔진 실행이 아니라는 점을 보여준다.
6. iPhone 실기에서 터치·키보드·스크롤·인쇄를 직접 확인한 뒤 배포한다.

## 기능 구현 후 제작할 영상
- 첫 스케치 → 치수 구속 → 돌출 → 잘라내기 → 수정 → 저장.
- 모델에서 연동 도면 만들기와 변경 갱신.
- 부품 조립, 구속과 간섭 확인.
- 파팅과 코어/캐비티 분리, 슬라이드 동작 확인.
- 셋업·공구·공정 → 가공 경로 → 장비용 NC → 검증.
- NC/조건표와 실제 Excel 가공 지시서의 자동 연결과 불일치 처리.

## 영상별 제공 묶음
영상 MP4, 한국어 자막 SRT/VTT, 단계별 문서 링크, 예제 파일, 기대 결과, 알려진 제한, 확인한 빌드 번호.
시청 후 수행할 짧은 과제를 붙이고 처음 쓰는 사용자가 완수하는지 확인한다.
