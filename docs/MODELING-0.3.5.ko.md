# 디엠아이 CAD 0.3.5 — 면 목록에서 스케치 시작

## 목적
솔리드의 평면 면 위치를 숫자로 옮겨 적지 않고 스케치 평면에 복사합니다. 정밀 OCCT 면에서 추출하며 표시 삼각형으로 평면을 추정하지 않습니다.
현재는 XY/XZ/YZ와 평행한 평면 면만 지원합니다. 곡면과 기울어진 면은 목록에 제공하지 않습니다.

## 작업 순서
1. 솔리드를 만들거나 DMI 프로젝트를 엽니다.
2. **스케치 탭 → 면에서 스케치**를 누릅니다.
3. 목록에서 면 번호·평면·위치(mm)·면적(mm²)을 보고 선택합니다. 같은 평면에 여러 면이 있으면 같은 위치가 표시될 수 있습니다. 면 번호는 현재 재계산 결과에서만 유효합니다.
4. 원/사각형을 선택하고, 파기를 하려면 **잘라내기용**을 체크한 채 스케치 시작을 누릅니다. 취소는 모델을 변경하지 않습니다.
5. 선택 면 위치가 평면 오프셋에 들어갑니다. 잘라내기용은 솔리드 안쪽, 추가용은 바깥쪽으로 기본 방향을 설정합니다.
6. 좌표·반지름 또는 너비·높이를 설정하고 **스케치 치수 적용 → 스케치 종료**를 누릅니다.
7. 피처 탭 → 돌출 컷(또는 돌출 보스/베이스) → 깊이나 끝까지 관통을 설정 → 확인합니다.
8. 저장하고 다시 열면 복사한 기준면·오프셋과 피처 이력이 복원됩니다.

좌표는 기존 전역 기준면 좌표입니다. 면 자체의 모서리를 원점으로 바꾸지 않습니다. 면의 면적 중심을 초기 좌표로 제안하지만, 구멍이나 오목한 면에서는 그 점이 재료 밖에 있을 수 있으므로 도형 좌표를 직접 확인하세요.
스케치 윤곽을 선택 면 영역으로 자동 제한하지 않습니다. 최종 추가/컷의 유효성과 단일 솔리드를 계산할 때 검사합니다.

## 중요한 제한
이는 **면 위치를 복사하는 기능**입니다. 면과 연결된 참조가 아닙니다. 예를 들어 윗면10 mm에서 시작한 스케치는 판 두께를15 mm로 바꿔도 오프셋10 mm에 남습니다. 다시 면에서 스케치를 시작하거나 기존 피처의 오프셋을 직접 고쳐야 합니다.
화면에서 면을 직접 클릭하거나 선택 면을 하이라이트하는 기능은 없습니다. 면 목록으로 선택합니다.
재계산·프로젝트 전환 시 목록을 갱신하며 이전 면 객체는 재사용하지 않습니다.
프로젝트는 기존 v3를 유지합니다. 0.3.4에서도 복사된 평면·오프셋에 따른 형상을 읽을 수 있지만 면 목록 기능은 0.3.5 이상에 있습니다.

## 검사
Windows CI에서 3개 기준면의 정확한 면적·면 위치·외측 방향, 면에서 가져온 설정으로 내부 관통 컷의 부피, 원통 곡면 제외를 검사합니다.
실제 GUI에서 윗면 데이터 → 원 스케치 → 안쪽 관통 컷 → 디스크 저장·재읽기·재계산 → 실행 취소를 검사합니다. 목록 대화상자 수동 조작, 모든 면 형상, 마우스/DPI/접근성과 초보 사용자 시험은 별도입니다.
