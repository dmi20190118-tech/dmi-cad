# 디엠아이 CAD 0.3.1 — 2020 기본 배치를 참고한 인터페이스

## 목적
SOLIDWORKS 2020에 익숙한 사용자가 명령·트리·속성·보기 도구를 찾기 쉽게 배치한다.
기존 디엠아이의 정확한 스케치/솔리드 엔진을 유지하고 실제 기능에 연결한다.
원본 로고는 디엠아이(DMI), 도구 아이콘은 자체 제작이다. 화면 전체의 픽셀 복제나 완전한 SOLIDWORKS 조작 호환을 뜻하지 않는다.

## 조사한 공식 2020 자료
- [CommandManager](https://help.solidworks.com/2020/English/SolidWorks/sldworks/c_commandmanager.htm): 작업별 명령 탭과 탭 하단 배치.
- [Manager Pane](https://help.solidworks.com/2020/english/SolidWorks/sldworks/c_management_panel.htm): 왼쪽 트리/속성 패널 전환.
- [PropertyManager](https://help.solidworks.com/2020/english/SolidWorks/sldworks/r_pm_overview.htm?format=P&value=): 속성의 확인/취소 흐름.
- [Heads-up View](https://help.solidworks.com/2020/english/SolidWorks/sldworks/c_heads_up_view_toolbar.htm): 모델 화면의 보기 도구.
- [Workspace Options](https://help.solidworks.com/2020/English/SolidWorks/sldworks/c_workspace_options.htm): 상단 명령·왼쪽 속성의 기본 작업 공간.

공식 2020 검색 자료로 구조를 확인했다. 도움말 원문을 직접 열면 동적 페이지 껍데기만 반환되는 경우가 있어, 실행 중인 SOLIDWORKS 2020과의 동시 비교나 픽셀 동일성 검증은 수행하지 않았다.

## 바뀐 배치

| 위치 | 디엠아이 화면 |
|---|---|
| 맨 위 | 파일·편집·보기·삽입·도구·작업 영역·도움말 메뉴 |
| 빠른 도구 | 새 부품·열기·저장·실행 취소/다시 실행·형상 정보 |
| 명령 영역 | 피처 / 스케치 / 검사·출력 탭, 자체 아이콘과 도구 설명 |
| 왼쪽 | 피처 트리와 속성 탭 전환, 트리 필터, 우클릭 편집 |
| 속성 | 확인·취소, 기준면/오프셋/깊이/스케치 치수 |
| 모델 화면 | 중앙 상단 보기 도구, 넓은 음영 화면, 좌표축 |
| 오른쪽 | 도움말·파일 뷰어·지시서 바로가기 |
| 하단 | 스케치·모델·형상 정보 화면 탭, 단위와 상태 |

3D 배경 격자를 제거했다. 실제 스케치 격자와 스냅은 유지한다.
기존 좌표계와 평면 방향은 바꾸지 않았다. XY→+Z, XZ→−Y, YZ→+X이며 보기 이름의 좌표 의미는 기존 모델을 기준으로 한다.

## 새로 만든 부품
1. 스케치 탭 → 사각형을 선택한다.
2. 왼쪽 속성에서 U/V·너비·높이를 입력하고 스케치 치수 적용을 누른다.
3. 스케치 종료 또는 속성의 확인으로 닫힌 스케치를 유지한다.
4. 피처 탭 → 돌출 보스 / 베이스를 선택한다.
5. 왼쪽 평면·오프셋·깊이를 설정한다.
6. 확인을 누르면 실제 형상을 계산한다. 취소/Esc는 미적용 작업을 취소한다.

## 기존 피처 수정
1. 트리에서 피처를 선택한다.
2. 우클릭 → 피처 정의 편집 또는 더블클릭한다.
3. 깊이·평면 등을 수정한다. 스케치 치수도 바꾸면 별도 치수 적용 버튼을 누른다.
4. 확인으로 재계산한다. 취소는 저장된 모델을 바꾸지 않는다.

스케치 편집도 우클릭 메뉴에서 시작할 수 있다. 변경한 스케치를 기존 피처에 적용하려면 속성 확인으로 피처 재계산을 마친다.
확인 전의 입력은 프로젝트에 반영된 모델이 아니다.

## 현재 기능의 한계
일반 구속 솔버, 임의 면/모서리 선택·정밀 측정, 필렛·모따기·곡면 편집, 도면·조립·금형·CAM/NC 생성은 아직 없다.
미지원 피처는 개발 예정으로 표시하고 비활성화한다. 오른쪽 지시서는 기존 초안 기능이며 자동 NC 대조는 아니다.
실제 여러 문서/도면을 관리하는 MDI 기능을 추가한 것은 아니다. 하단은 현재 부품의 보기 탭이다.

## 이번 변경의 검사
- 기존 형상·변환·부피·표시·저장 검사 유지.
- 실제 GUI에서 스케치 정의, 속성 전환, 확인에 의한 피처 추가, 취소에 의한 모델 보존 검사.
- 실행 취소/다시 실행 및 트리 필터 검사.
- 기본 모델 화면과 속성 화면 캡처.
- Windows 설치파일 생성.

자동 검사는 전체 수동 마우스 조작, 키보드 접근성, Windows 배율별 레이아웃, 실제 SOLIDWORKS 사용자 비교 시험을 대체하지 않는다. 완전한 디자인 감사나 접근성 적합 판정으로 설명하지 않는다.
