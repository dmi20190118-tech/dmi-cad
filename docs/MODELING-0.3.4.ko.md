# 디엠아이 CAD 0.3.4 — 관통 컷

## 목적과 사용
판 두께를 수정해도 선택한 방향의 모든 재료를 통과하도록 컷 길이를 다시 계산합니다. 이전 솔리드의 정밀 형상 범위를 기준으로 하며 입력 깊이 값은 사용하지 않습니다.

1. 스케치에서 사각형/원/닫힌 다각형을 만들고 치수를 적용한 뒤 종료합니다.
2. 피처 → 돌출 보스/베이스 → 평면·오프셋·깊이 → 확인으로 솔리드를 만듭니다.
3. 원 스케치를 만들고 치수 적용 → 종료 → 돌출 컷을 선택합니다.
4. 평면과 오프셋을 설정하고 **끝까지 관통**을 선택합니다. 깊이 및 중간 평면 입력은 비활성화됩니다.
5. 기본 방향은 XY:+Z, XZ:−Y, YZ:+X입니다. 반대 방향으로 뚫으려면 반대 방향을 체크합니다.
6. 확인으로 컷을 생성합니다. 트리의 관통 표시를 확인합니다.
7. 이전 피처 깊이를 수정하면 관통 길이도 재계산됩니다. Ctrl+Z/Y로 취소/다시 실행합니다.
8. .dmipart를 저장하고 다시 열면 피처 이력과 관통 조건을 복원합니다.

예: XY 사각형20×10 mm, 깊이10 mm를 생성합니다. XY 오프셋0에서 중심(5,5), 반지름2 mm인 원으로 +Z 관통 컷을 만듭니다. 첫 피처 깊이를25 mm로 수정해도 구멍은 끝까지 뚫립니다.
윗면에서 아래로 파려면 XY 오프셋을 윗면 높이로 정하고 반대 방향을 체크합니다. 이 오프셋은 숫자이며 윗면에 자동 연결된 참조가 아닙니다. 윗면 높이가 변하면 오프셋도 직접 수정해야 합니다.

## 복구와 제한
솔리드와 만나지 않는 방향·위치, 완전히 제거되는 솔리드, 중간 평면과 관통 동시 사용, 재료 추가의 관통은 거부합니다. 기준면·오프셋·방향을 확인하세요. 실패하면 기존 모델을 유지합니다.
현재 관통은 **선택한 한 방향**에만 적용합니다. 스케치 평면 뒤쪽 재료까지 양방향 제거하는 기능은 아닙니다.
기준면은 XY/XZ/YZ 및 숫자 오프셋입니다. 제품 면 클릭, 임의 각도 평면, 면과 연결되는 스케치, 호·일반 구속 솔버는 아직 없습니다.
확인 전 실시간 형상 미리보기는 제공하지 않습니다.

## 파일 형식
새 저장 형식은 v3이며 앱0.3.4 이상에서 사용합니다. v1/v2는 읽어 메모리에서 v3로 변환합니다. 이전 앱은 v3를 거부해 새 컷 조건을 무시하지 않도록 합니다. 원본 보존이 필요하면 다른 이름으로 저장하세요.

## 검사 범위
Windows CI는 3개 평면·양쪽 방향·10/25 mm 두께의 정확한 STEP 부피, 잘못된 설정 거부, 실제 GUI의 관통 편집·두께 수정·디스크 저장/재읽기·재계산·실행 취소를 검사합니다. 전체 수동 마우스·설치 후 환경별 검사는 별도입니다.
