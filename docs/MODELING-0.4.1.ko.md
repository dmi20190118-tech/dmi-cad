# DMI CAD 0.4.1 — 돌출 끝 평면 연결

## 목적
판 두께 등 이전 돌출 깊이를 수정할 때, 그 돌출의 끝에서 시작한 스케치 평면도 자동 이동시킵니다. 연결의 기준은 저장된 피처 식별자이며 재계산 때 바뀔 수 있는 화면 면 번호가 아닙니다.

## 작업 순서
1. 사각형을 스케치하고 깊이10 mm로 한 방향 돌출합니다.
2. 스케치 → 화면 면 선택 → 윗면 클릭 → 선택면 스케치.
3. 속성창의 **돌출 끝 평면 연결**과 **참조 돌출** 이름을 확인합니다. 연결되면 기준면/오프셋은 직접 편집할 수 없습니다.
4. 원의 좌표/반지름 입력 → 치수 적용 → 스케치 종료 → 돌출 컷 → 끝까지 관통 → 확인.
5. 첫 돌출의 깊이를15 mm로 수정하고 확인합니다. 연결된 컷의 시작 평면도15 mm로 이동합니다.
6. 컷을 선택해 피처 정의 편집을 열면 현재 계산된 평면 위치가 표시됩니다.
7. 저장·다시 열기 및 Ctrl+Z/Y에서도 참조를 유지합니다.

연결은 선택한 평면 위치/외측 방향과 **유일하게 일치하는 이전 한 방향 재료 추가 돌출의 끝 평면**을 찾았을 때 자동 설정됩니다. 여러 돌출이 겹쳐 출처가 모호하거나, 옆면·시작면·중간 평면 돌출 등 지원하지 않는 면이면 고정 위치로 복사합니다. 연결 표시를 반드시 확인하세요.
이는 임의의 면 경계/모서리를 영구 추적하는 기능이 아니라 **피처의 끝 평면을 참조하는 기능**입니다. 스케치 좌표는 기존 기준면의 전역 좌표이며, 너비·높이 변경에 따른 중심/모서리 위치까지 자동 추적하지 않습니다.

## 연결 해제와 오류
연결 체크를 끄면 속성에 표시된 현재 위치를 고정값으로 사용할 수 있습니다. 확인해야 모델에 반영되며 취소/Esc는 기존 모델을 유지합니다.
참조 돌출 삭제, 중간 평면 방식으로 변경, 기준면 변경 등으로 참조가 유효하지 않으면 재계산을 거부하고 기존 모델을 유지합니다. 후속 피처에서 연결을 먼저 해제하거나 지원하는 참조를 복원하세요.
연결은 앞선 피처만 참조할 수 있으며 자기 자신·뒤쪽 피처·순환 참조는 거부합니다. 연결된 돌출을 다시 참조하는 연쇄 연결은 지원합니다.

## 파일 호환
새 프로젝트는 **v4**로 저장합니다. v1/v2/v3 파일은 읽고 v4로 저장할 수 있지만 이전 앱은 v4를 열지 못합니다. 원본 보존이 필요하면 다른 이름으로 저장하세요.
고정 위치 프로젝트를 열었다고 자동으로 참조를 추측해 바꾸지는 않습니다. 새로 면에서 스케치를 시작할 때 연결을 찾습니다.

## 검증
3개 기준면·두께10/25 mm에서 연결된 시작 평면과 컷 부피, 연쇄 참조, 삭제/잘못된 기준면/순환/중간 평면 참조 거부, 문서 복사·저장 구조를 CI에서 검사합니다.
실제 GUI에서 화면 면 선택 → 연결된 원/관통 컷 → 이전 깊이 변경 → 속성의 갱신된 위치 → 디스크 저장/재읽기/재계산 → 실행 취소를 검사합니다.
자동 검사는 프로그램 내 마우스 이벤트 호출을 사용합니다. 전체 실제 마우스·DPI·접근성·초보 사용자 시험은 별도로 남아 있습니다.
