# 디엠아이 CAD 0.3 — 실제 스케치와 솔리드 모델링

## 무엇이 바뀌었나요?
기본 창이 파일 뷰어에서 스케치·피처 모델링 창으로 바뀝니다.
닫힌 다각형과 원을 정의하고 Open CASCADE의 정확한 솔리드로 돌출·결합·빼기를 합니다.
표시만 바뀌는 예제 상자와 달리 직접 만든 스케치와 피처가 프로젝트에 저장되고 STEP으로 출력됩니다.

## 시작하기: 숫자로 플레이트 만들기
1. 사각형을 누릅니다.
2. U=0, V=0, 너비=100, 높이=70을 입력합니다.
3. 치수 적용을 누릅니다. 2D에 닫힌 사각형이 나타납니다.
4. 평면 XY, 오프셋=0, 깊이=10을 입력합니다.
5. 돌출 추가를 누릅니다.
6. 계산이 완료되면 3D 솔리드 탭에서 100×70×10 플레이트를 확인합니다.
7. 형상 정보 / 검증 탭에서 실제 엔진의 부피를 확인합니다. 이 예제는 70,000 mm³입니다.

마우스로 그릴 때는 사각형의 대각 두 점, 원의 중심과 둘레, 다각형의 꼭짓점을 왼쪽 버튼으로 찍습니다.
다각형은 점 세 개 이상을 찍고 스케치 닫기를 누르거나 첫 점을 다시 누릅니다.
스냅 간격의 단위는 mm입니다.

## 원 구멍 만들기
1. 원을 누릅니다.
2. U=50, V=35, 반지름=10을 입력하고 치수 적용을 누릅니다.
3. XY / 오프셋=0 / 깊이=10을 설정합니다.
4. 잘라내기를 누릅니다.
5. 기존 플레이트에서 반지름 10의 관통 구멍이 제거되는지 확인합니다.

현재 관통 옵션은 별도 버튼이 아니라 시작 오프셋과 깊이로 정의합니다. 지정 깊이가 실제 몸체를 관통하는지 직접 확인하세요.

## 상단에 보스 추가하기
사각형 U=5, V=5, 너비=20, 높이=20 → 치수 적용 → XY / 오프셋=10 / 깊이=15 → 돌출 추가.
공간에 떨어진 별개 입체는 현재 단일 솔리드 제한으로 거절합니다. 기존 몸체와 이어지도록 설정하세요.

예제 만들기 버튼은 위 세 피처를 실제 엔진으로 계산합니다.

## 피처 수정과 실행 취소
1. 왼쪽 트리에서 피처를 선택합니다.
2. 원의 중심·반지름, 사각형 치수 또는 다각형 꼭짓점 좌표를 수정합니다.
3. 치수 적용을 누릅니다. 이는 아직 2D 스케치 수정입니다.
4. 깊이·평면·오프셋도 필요하면 바꿉니다.
5. 피처 수정을 누르면 이후 피처까지 순서대로 다시 계산합니다.
6. 실패하면 기존 모델과 프로젝트를 유지하며 오류를 표시합니다.
7. Ctrl+Z / Ctrl+Y 또는 실행 취소 / 다시 실행 버튼을 사용합니다.

다각형은 꼭짓점 번호를 선택한 뒤 U/V를 바꾸고 치수 적용을 누릅니다.
일반 기하 구속 솔버는 아직 없으며 사각형·원의 숫자 치수와 꼭짓점 좌표를 직접 정의하는 방식입니다.

## 평면과 방향
| 평면 | U / V | 오프셋 좌표 | 양의 깊이 방향 |
|---|---|---|---|
| XY | X / Y | Z | +Z |
| XZ | X / Z | Y | −Y |
| YZ | Y / Z | X | +X |

임의의 모델 면에 스케치를 붙이는 기능은 아직 없습니다.

## 저장과 내보내기
- 저장: .dmipart에 프로젝트 버전, mm 단위, 스케치와 피처 이력을 저장합니다.
- 열기: 저장된 피처를 다시 계산합니다.
- 내보내기: 정확한 형상을 STEP/IGES로, 삼각형 표시 형상을 STL로 출력합니다.
- 기존 .dmicad 예제 파일과 .dmipart 피처 프로젝트는 서로 다른 형식입니다.
- 아직 돌출/잘라내기/피처 수정에 적용하지 않은 임시 스케치는 저장하지 않습니다.

기존 STEP/IGES/STL/DXF 파일은 파일 뷰어 버튼으로 별도 창에서 엽니다. 가져온 모델을 이 피처 트리에서 편집하는 기능은 아직 없습니다.

## 가공 지시서 연결
가공 지시서를 누르면 모델 이름, 프로젝트 리비전, 표시 메시의 외형 범위를 초안에 전달합니다.
이것은 작성 시점의 복사본입니다. 모델 수정 후에는 새로 작성해야 합니다.
NC 공구·이송·원점의 자동 추출이나 NC 대조는 아직 없습니다.

## 검증과 제한
형상 엔진은 유효한 단일 솔리드, 양의 부피, 자기교차 없는 닫힌 스케치와 실제 재료 변화 여부를 확인합니다.
빈 잘라내기, 분리된 추가 입체, 잘못된 좌표·깊이는 거절합니다.

한 프로젝트 최대 100피처 / 다각형 최대 500점 / 프로젝트 1MB / 깊이 최대 10,000mm.
표시 메시 제한은 기존 25만 삼각형이며 변환·재계산 시간 제한은 3분입니다.
유효한 솔리드라는 검사만으로 금형 제작 가능성, 가공 안전 또는 치수 공차 충족을 보장하지 않습니다.

아직 없는 기능: 일반 구속 솔버, 필렛/모따기, 임의 곡면 편집, 정밀 면/모서리/점 선택·측정, 연동 도면, 조립, 금형 설계, CAM/NC 생성·충돌 검사·최적화, 실제 Excel 자동 양식.

## 마우스와 도움말
3D: 가운데 버튼 회전, Ctrl+가운데 이동, Shift+가운데 확대, 휠 확대/축소, 가운데 버튼 더블클릭 화면 맞춤.
2D: 왼쪽 버튼 점 입력, Ctrl+가운데 이동, 휠 확대/축소.
F1: 창 안의 시작하기 도움말. 각 버튼을 가리키면 작업 설명 툴팁이 나옵니다.

실제 스케치 선택/다각형 클릭/프린트의 수동 검증과 실제 사용자에 의한 작업 테스트는 자동 검사와 별도로 필요합니다.
