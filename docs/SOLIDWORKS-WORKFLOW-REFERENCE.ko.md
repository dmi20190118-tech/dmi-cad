# SOLIDWORKS 작업 순서 참조와 DMI 적용 — 1.0 개발판 3

## 확인한 자료와 범위
- [SOLIDWORKS 2020 — Sketching with Planes](https://help.solidworks.com/2020/english/solidworks/sldworks/t_Sketching_with_Planes.htm): 검색에 색인된 공식 본문에서 기준면 선택, 스케치 도구, 치수, 스케치 종료/피처 생성 순서를 확인했습니다. 직접 열기는 동적 도움말의 공통 화면만 반환했습니다.
- [공식 2020–2021 Fundamentals PDF](https://www.solidworks.com/sites/default/files/2020-05/Fundamentals3DDesign-SIM-ENG-SV.pdf): PDF의 기본 모델링 설명과 그림을 확인했습니다. 인쇄쪽70~71(파일83~84번째 쪽)은 첫 돌출 이후 제품의 평면 면을 다음 스케치 평면으로 사용하는 예를 다룹니다.
- [공식 Sketching and Dimensioning the Boss](https://help.solidworks.com/2024/English/swconntutorial/t_tut_lesson1_boss_adding.htm): 색인된 본문에서 제품 면 사전 선택, 보스 명령, 수직 보기, 원과 치수 입력 순서를 확인했습니다. 2024 자료이므로 2020의 정확한 화면 배치 검증으로 사용하지 않습니다.
- [공식 면 위 컷 시연 페이지](https://help.solidworks.com/2023/english/SolidWorks/sldworks/c_video_instant3d_sketch_all_on_face.htm), [2020 Rapid Sketch](https://help.solidworks.com/2020/English/SolidWorks/sldworks/t_Using_RapidSketch.htm): 시연 페이지와 설명을 찾았지만 영상 재생 프레임/자막은 확인하지 못했습니다. 동영상을 직접 보고 검증했다고 주장하지 않습니다.

확인된 공통 흐름은 **면/평면 선택 → 그 평면에 스케치 → 치수 정의 → 보스/컷 조건 → 확인 → 다음 면 선택**입니다. DMI에서 아래 안내를 도출한 것은 독립적인 제품 설계 판단이며 SOLIDWORKS가 똑같은 안내바를 제공한다는 뜻은 아닙니다.

## DMI에 구체적으로 반영한 동작
1. 화면에 항상 ① 면/평면 선택 → ② 2D 스케치 → ③ 보스/컷 단계를 표시합니다.
2. 모델 면을 클릭하면 주황색 선택과 면 번호·기준면·현재 위치(mm)를 표시하고 **이 면에서 스케치 시작**을 활성화합니다.
3. 첫 부품은 안내바의 XY/XZ/YZ를 고른 뒤 **이 기준면에서 스케치 시작**을 누릅니다. 새 부품에서 몰래 기본 평면에 스케치를 시작하지 않습니다.
4. 스케치 중에는 현재 평면/위치, 옅은 선택 면 배경, 사각형·원 도구를 표시합니다. 좌표·현재 도형 치수와 스냅만 왼쪽에 보이며 회전각·필렛 등 무관한 입력은 숨깁니다.
5. 도형을 닫으면 **위로 쌓기 · 돌출 보스 / 안으로 파기 · 돌출 컷**을 같은 안내바에서 바로 선택합니다. 중간의 종료 버튼 순서를 외울 필요가 없습니다.
6. 피처 단계에는 깊이/방향 등 필요한 조건과 **형상 계산/확인**을 표시합니다. **스케치로 돌아가기**로 도형을 수정할 수 있습니다.
7. 확인 후 다음으로 쌓거나 팔 제품 면을 클릭하라고 안내합니다.
8. 트리에는 필렛은 반지름, 회전은 각도를 표시하며 사용하지 않는 돌출 깊이를 표시하지 않습니다.

## 직접 해 보기
- 새 부품 → XY → 이 기준면에서 스케치 시작 → 사각형 대각 두 점 → 위로 쌓기 → 깊이10 → 형상 계산/확인.
- 제품 윗면 클릭 → 이 면에서 스케치 시작 → 원 → 중심/둘레 클릭 → 위로 쌓기 → 깊이8 → 확인.
- 보스 윗면 클릭 → 이 면에서 스케치 시작 → 원 → 도형 작성 → 안으로 파기 → 끝까지 관통 → 확인.
숫자로 치수를 지정할 때는 **치수 적용 또는 Enter**로 스케치에 반영합니다.

## 실제 지원 범위와 남은 차이
현재는 XY/XZ/YZ에 평행한 평면만 지원합니다. 스케치 배경은 시각 참조이며 모서리 스냅/일반 구속이 아닙니다. 임의 경사 평면, 일반 치수 구속, 호, 라이브 돌출 미리보기 등은 이번 수정으로 완성된 기능이 아닙니다.
돌출 끝 평면 연결은 조건에 맞는 경우만 자동 설정되며 임의 면 경계 영구 참조는 아닙니다.
동영상/도움말을 참고한 동작 흐름의 개선이며 SOLIDWORKS 실행본과의 완전한 조작 대조 시험은 아닙니다.

## 검사
Windows CI에서 안내바의 실제 버튼 동작, 선택 면/평면 위치 표시, 닫힌 스케치의 다음 동작, 보스/컷 확인 단계, 정밀 부피·저장 복원·실행 취소를 검사합니다.
자동 검사는 프로그램 내 마우스/버튼 이벤트를 호출합니다. 사용자 PC의 실제 마우스·DPI·접근성과 초보 사용자 따라하기 검증은 별도입니다.
