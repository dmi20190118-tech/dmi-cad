# DMI CAD 사용자 안내서

문서 기준: 2026-10-24 / Windows 0.2 계열 시제품 및 모바일 체험판  
대상: 처음 사용하는 설계자·가공 담당자·현장 작업자  
이 문서는 현재 작동하는 기능을 설명합니다. 개발 예정 기능은 사용 절차로 설명하지 않습니다.

## 1. 이 프로그램은 무엇을 하는가

목표는 제품을 설계한 뒤 도면·조립·금형·가공 경로·NC·가공 지시서까지 같은 프로젝트에서 연결하는 것입니다.

현재는 그 목표의 초기 단계입니다. Windows 버전에서는 지원 CAD 파일을 열어 형상을 확인하고, 일부 형식을 변환하고, 가공 지시서 초안을 작성할 수 있습니다. 직접 스케치를 그려 입체를 설계하는 정밀 CAD와 자동 NC 생성 기능은 아직 없습니다.

모바일 체험판은 조건 입력·점검·시트 보기와 예제 직육면체 조작을 체험하는 화면입니다. Windows 앱을 원격 실행하는 화면이 아닙니다.

### 현재 가능한 일과 불가능한 일

| 작업 | 상태 |
|---|---|
| STEP·IGES 읽기 및 표시 | 구현, 단일 표시 형상 중심 |
| STL 및 제한적인 ASCII DXF 읽기 | 구현, 아래 제한 확인 |
| 회전·화면 이동·확대·화면 맞춤 | 구현 |
| STEP/IGES 원본의 STEP·IGES·STL 변환 | 구현, 속성·형상 변환 결과 검토 필요 |
| 가공 지시서 수동 입력·기본 점검·인쇄용 HTML | 구현된 시제품 |
| 선·원 스케치, 치수 구속, 돌출·잘라내기 | 개발 예정 |
| 연동 도면·조립 구속·코어/캐비티·슬라이드 | 개발 예정 |
| 가공 경로·NC 생성·충돌 검증·시간 최적화 | 개발 예정 |
| Excel 양식 자동 작성, NC와 시트 자동 대조 | 양식·조건표 확보 후 구현 예정 |
| PFM·시마트론·솔리드웍스·카티아·DWG 원본 읽기 | 미지원, 변환기와 형식별 검증 필요 |

## 2. 설치하고 처음 실행하기

1. Windows 10/11 x64 PC에서 전달받은 설치 ZIP을 풉니다.
2. DMI-CAD-Setup-0.2.0.exe를 실행하고 설치 위치를 확인합니다.
3. 시작 메뉴 또는 바탕화면의 DMI CAD를 실행합니다.
4. 상단 메뉴, 왼쪽 모델 트리, 가운데 작업 화면이 표시되는지 확인합니다.

별도 .NET이나 Python 설치는 필요하지 않도록 묶여 있습니다. 초기 배포본은 코드 서명이 없습니다. 경고가 나오면 출처와 파일 버전을 확인하고, 회사 PC에서는 사내 설치 정책을 따르세요.

같은 0.2.0 이름으로 초기 기능을 추가해 온 상태이므로 기능 확인에는 배포한 GitHub 빌드 번호도 함께 기록해야 합니다. 이후 정식 릴리스부터 버전과 빌드를 명확히 구분하는 것이 개발 과제입니다.

## 3. 5분 안에 모델 열어보기

### 파일 준비

처음에는 STEP 파일을 권합니다. 원래 CAD에서 내보낼 때 단위와 형상 포함 여부를 확인하세요.

1. 상단 파일 → 열기를 누릅니다.
2. STEP(.step/.stp), IGES(.iges/.igs), STL 또는 지원되는 DXF를 선택합니다.
3. 읽기가 끝나면 파일 이름, 형상과 모델 트리의 크기 정보를 확인합니다.
4. 가운데 버튼을 빠르게 두 번 눌러 화면에 맞춥니다.
5. 회전하여 뒤쪽과 옆면도 확인합니다.

파일이 열렸다는 사실만으로 원본과 완전히 같은 모델임이 보장되는 것은 아닙니다. 기준 치수, 면 누락, 방향, 단위를 원본과 비교하세요. 현재 정밀 치수 측정 도구는 아직 없습니다.

### Windows 마우스 조작

| 하고 싶은 일 | 조작 |
|---|---|
| 모델 돌려보기 | 가운데 버튼을 누른 채 드래그 |
| 화면에서 위치 이동 | Ctrl + 가운데 버튼 드래그 |
| 확대·축소 | 휠 또는 Shift + 가운데 버튼 드래그 |
| 화면 전체에 맞추기 | 가운데 버튼 더블클릭 또는 화면 맞춤 |
| 정면·평면·등각으로 보기 | 작업 화면 위의 해당 버튼 |
| 모서리 중심으로 보기 | 표시 탭의 와이어프레임 |

왼쪽 버튼으로 면·선·점을 정밀 선택하는 기능과 SOLIDWORKS 전체 조작 호환은 아직 없습니다.

### 예제 직육면체와 가져온 모델의 차이

왼쪽 치수 입력은 프로그램의 예제 직육면체에 사용합니다. 가져온 CAD 모델의 피처 치수를 수정하는 기능이 아닙니다. 가져온 모델에서는 이 치수 입력을 사용할 수 없도록 되어 있습니다.

## 4. 파일을 변환하기

1. STEP 또는 IGES 파일을 엽니다.
2. 파일 → 변환 / 내보내기를 누릅니다.
3. 출력 형식과 저장할 파일 이름을 선택합니다.
4. 저장한 결과를 다시 열어 형상을 비교합니다.

STEP·IGES는 원본 형상을 엔진으로 다시 읽어 변환합니다. STL은 삼각형 메시이므로 정밀 곡면·피처 이력이 유지되지 않습니다. 조립 구조·재질·PMI·편집 이력 보존도 보장하지 않습니다.

DXF 선 도면을 STL 입체나 STEP 솔리드로 자동 변환하는 기능은 없습니다.

파일 제한은 현재 128 MB, 표시 메시 25만 삼각형, CAD 엔진 처리 3분입니다. 큰 파일이 거절되면 파일을 분할하거나 거친 메시로 내보내세요.

## 5. 가공 지시서 초안 만들기

### 준비할 정보

- NC 프로그램명, 제품·도면번호와 리비전
- 공정, 장비·컨트롤러, 소재, 가공 원점과 고정 방법
- 공구번호, 지름, 날 수
- 회전수·이송·절입 깊이·절삭 폭
- 작업 치수·공차, 소재 크기·잔삭 여유
- 대조할 조건표의 값·출처·버전과 작업자 주의사항

### 작성 순서

1. 상단 가공 지시서 메뉴를 엽니다.
2. 한 공정의 정보를 입력합니다. 아직 여러 공정 자동 집계 양식은 아닙니다.
3. 입력 점검을 누릅니다.
4. 오류가 나오면 해당 입력을 수정합니다.
5. 확인 필요 항목은 실제 도면·NC·조건표를 보며 검토합니다.
6. 초안 저장을 누르면 .dmisheet 파일로 보관할 수 있습니다.
7. 인쇄용 시트를 누르면 브라우저에서 HTML 시트가 열립니다.
8. 브라우저의 인쇄 / PDF 저장 기능으로 출력합니다.

인쇄용 HTML은 해당 PC의 사용자 AppData/Local/DMI CAD/Sheets 아래에 저장됩니다. 민감한 도면번호나 조건이 포함된 경우 회사의 문서 보관 정책을 적용하세요.

현재 지시서는 NC 원본과 자동 대조하지 않습니다. 입력 검사 통과는 가공 승인이나 충돌 없음 판정이 아닙니다.

### 검사 메시지 읽는 법

| 표시 | 의미 | 해야 할 일 |
|---|---|---|
| 입력 누락 / 양수·정수 필요 | 필수 정보가 없거나 숫자 형식이 잘못됨 | 단위와 입력을 수정 |
| 회전수·이송 최대값 초과 | 사용자가 입력한 참조 최대값보다 큼 | 장비·공구·조건표와 대조 |
| ae가 공구 지름보다 큼 | 절삭 폭과 지름의 관계가 맞지 않음 | 입력 항목·단위·작업 방식 확인 |
| 참조 Vc/fz와 5% 넘게 다름 | 입력 S/F와 참조 조건의 계산 결과가 다름 | 조건 변경 의도와 원본 확인 |
| 기본 입력 검사 통과 / 검토 필요 | 구현된 기본 규칙에 오류가 없다는 뜻 | NC·치수·원점·셋업을 별도로 확인 |

5%는 시제품의 단순 불일치 알림 기준입니다. 가공 허용 공차나 안전 범위가 아닙니다.

## 7. 자주 막히는 상황

| 증상 | 가능한 원인 | 해결 순서 |
|---|---|---|
| 파일 형식 미지원 | PFM·DWG 등 원본 변환기 없음 | 원래 CAD에서 STEP/IGES/기본 DXF로 내보내기 |
| DXF 읽기 중단 | 블록·텍스트·스플라인·불지 등 미지원 요소 | 복사본을 기본 지원 요소로 분해해서 내보내기 |
| 모델이 안 보임 | 화면 이동·확대 상태 또는 표시할 면 없음 | 화면 맞춤 → 다른 보기 → 파일 형상 확인 |
| 크기가 예상과 다름 | 내보내기 단위 불일치 | 원본 단위와 파일 좌표 확인 |
| CAD 읽기 엔진 없음 | 설치 파일/구성요소 누락 | 공식 전달본으로 재설치 |
| 시트 출력 버튼이 진행되지 않음 | 필수·숫자·범위 오류 | 입력 점검 결과부터 수정 |
| 미리보기에는 있는데 PC 메뉴가 없음 | 다른 배포 빌드 또는 플랫폼 기능 차이 | 버전·빌드 번호와 기능 상태 확인 |

문제가 계속되면 파일 형식, 프로그램 버전/빌드, 재현 순서, 오류 문구, 기대한 결과를 함께 알려주세요. 고객 모델을 공개 게시판에 올리지 말고 공유 권한을 확인하세요.

## 8. 기본 용어

- 스케치: 평면 위에 그리는 선·원 등의 설계 도형.
- 구속: 수평·평행·동심 등의 관계를 유지하는 조건.
- 솔리드: 부피를 가진 입체 형상.
- 곡면: 면 형상. 닫혀 있지 않으면 부피가 있는 입체가 아닐 수 있음.
- 피처: 돌출·잘라내기·필렛처럼 형상을 만드는 작업과 그 이력.
- 메시: 형상을 작은 삼각형 등으로 표현한 데이터.
- 어셈블리: 여러 부품을 배치·구속한 조립 모델.
- 파팅: 금형이 열리는 경계를 정하고 분할 형상을 만드는 작업.
- 코어·캐비티: 제품 형상을 성형하는 금형의 두 주요 형상 영역.
- 슬라이드·리프터: 언더컷 등의 이형을 위해 추가 방향으로 움직이는 금형 기구.
- 원점·좌표계: 치수와 공구 위치를 해석하는 기준.
- S: 주축 회전수. 이 시제품의 단위는 rpm.
- F: 공구 이송. 이 시제품의 계산은 mm/min 기준.
- ap / ae: 절입 깊이 / 절삭 폭.
- Vc / fz: 절삭속도 / 날당 이송.
- 포스트프로세서: 가공 경로를 특정 장비·컨트롤러용 NC로 변환하는 구성요소.

도움말에 용어가 있다는 사실이 해당 기능의 구현을 뜻하지는 않습니다.
