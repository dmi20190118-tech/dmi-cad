# DMI CAD 1.0 개발판 1 — 통합 모델링 묶음

정식 1.0 완성판이 아닌 기능 개발판입니다. 기존 작은 버전 배포 대신 회전 형상·전체 모서리 필렛과 새 예제를 묶었습니다.

## 제공 기능
- 사각형·원·닫힌 다각형 스케치와 좌표·크기 입력
- 깊이 돌출·컷, 반전·중간 평면·한 방향 관통
- 화면 면 선택과 주황색 표시, 지원되는 돌출 끝 평면 연결
- **회전 보스·회전 컷**: 스케치의 세로 V축(U=0) 주위로0.001~360° 회전
- **전체 모서리 필렛**: 지정 반지름으로 기존 솔리드의 모든 모서리 둥글게
- 피처 편집·삭제·재계산·실행 취소/다시 실행·프로젝트 저장/열기
- STEP/IGES/STL 출력과 기존 파일 뷰어·수동 가공 시트

## 먼저 실행할 예제
검사/출력 탭 → **1.0 금속 플레이트**: 필렛 플레이트, 큰 관통 구멍, 원형 보스와 보스 구멍을 정밀 엔진으로 생성합니다.
검사/출력 탭 → **회전 부품**: 단차 단면을 360° 회전해 중공 축을 생성합니다.
트리에서 피처 선택 → 피처 편집 → 필렛 반지름 또는 회전각을 수정 → 확인으로 실제 형상이 바뀝니다.
예제 프로젝트는 examples/plate-1.0-preview1.dmipart와 examples/turned-1.0-preview1.dmipart에 있습니다.

## 회전 형상 직접 만들기
1. 새 부품 → 스케치 사각형을 선택합니다.
2. U=10, V=0, 너비=10, 높이=30 mm → 치수 적용 → 스케치 종료.
3. 피처 → 회전 보스 → XY/XZ/YZ 평면 선택. **스케치 세로 V축이 회전축**이며 U=0을 지납니다.
4. 회전각360° → 확인하면 바깥 반지름20, 안쪽 반지름10, 길이30 mm의 중공 회전체가 됩니다.
5. 180°로 수정하면 절반 회전체가 됩니다. 반대 방향은 축 회전 방향을 바꿉니다.
6. 기존 솔리드의 홈은 별도 단면을 스케치하고 회전 컷으로 만듭니다.

프로파일은 U≥0 쪽에 있어야 하며 회전축을 가로지르면 거부합니다. 임의 선 선택 회전축·중간 평면·관통은 회전에서 지원하지 않습니다. XZ 평면의 V축은 전역 Z축입니다.

## 필렛 직접 만들기
1. 솔리드를 만든 뒤 피처 → **전체 모서리 필렛**.
2. 필렛 반지름(mm)을 입력하고 확인합니다. 스케치를 따로 만들 필요가 없습니다.
3. 복잡한 형상·작은 구멍·큰 반지름 조합은 실패할 수 있습니다. 반지름을 줄이거나 필렛을 구멍/보스 이전 단계에서 적용하세요.
4. 실패 시 기존 확정 모델을 유지합니다.
이번 필렛은 특정 모서리 선택 방식이 아닙니다. 전체 모서리만 처리합니다.

## 평면 연결과 파일
화면 면 선택 및 돌출 끝 평면 연결은 이전 기능을 유지합니다. 모든 면이 연결되는 것은 아니며 기준면 XY/XZ/YZ와 평행한 평면만 스케치할 수 있습니다. 임의 면의 경계·모서리 위치 영구 추적은 아닙니다.
새 프로젝트 형식은 **v5**입니다. v1~v4를 읽고 v5로 저장합니다. 이전 앱은 v5를 열지 못합니다. 원본 보존에는 다른 이름으로 저장하세요.
회전/필렛의 피처 종류·각도·반지름은 프로젝트에 저장되고 정밀 엔진으로 재계산합니다.

## 정식 1.0까지 남은 항목
일반 스케치 치수/기하 구속 솔버, 호, 모서리/꼭짓점 선택과 정밀 측정, 선택 모서리 필렛, 임의 평면, 도면·조립 및 사용자 환경별 수동 검증이 아직 없습니다.
금형 설계·CAM/NC 생성·충돌 검증·엑셀 자동 시트는 개발 목표이며 이번에 완성된 기능이 아닙니다.

## 자동 검증
3개 평면의 회전체 정확한 부피·180°/반전·회전 컷·필렛의 이론 부피·반지름 수정·잘못된 조건 거부를 기존 검사에 추가했습니다.
실제 Windows GUI에서 회전각/필렛 편집·실행 취소·저장 재읽기·재계산을 실행하고 새 예제 화면을 캡처합니다. 검사 성공 여부는 빌드 결과를 확인합니다.
자동 GUI 검사는 프로그램 이벤트 호출이며 사용자의 전체 마우스·DPI·설치 후 환경·접근성 시험은 별도입니다.
