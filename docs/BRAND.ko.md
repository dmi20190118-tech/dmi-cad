# DMI 브랜드 기준

![DMI 원본 로고](https://static.wixstatic.com/media/b61e9b_4c68109deaca422494f28c350edb38de~mv2.png)

- D: Design — 제품 설계
- M: Mold — 금형
- I: Injection — 사출·양산

사용자가 예전에 보관한 [DMI로고.png](https://drive.google.com/file/d/1oo4KLBoZrp6ecmCcKki18gxx8SVH5LFM/view)를 사용한다.
주황 D, 초록 M, 파랑 I의 원본 모양·색·비율·문구를 유지한다.
라벨이 보이도록 흰 배경과 충분한 크기를 확보한다.

프로그램 상단, 인쇄용 지시서, 도움말과 교육 자료에서 일관되게 사용한다.
웹 미리보기는 Wix에 올린 원본 이미지 URL을 사용하고, Windows와 로컬 출력물은 오프라인 사용을 위해 원본 바이트를 포함한다.

음성으로 TMI라고 언급되었으나 확인된 파일명과 설명된 이니셜은 DMI이다. 별도의 TMI 로고가 의도된 경우 실제 원본을 확인해 교체한다.
