This is an independent browser prototype of the machining-sheet flow with a touch-operated sample cuboid. It is not the Windows executable, a remote desktop session, a STEP/PFM importer or NC verification.

Features: sample condition input, required/numeric/reference checks, Vc/fz calculation, printable draft, local JSON draft download/import, sample cuboid rotation/pinch/pan and dimensions. Input stays in the browser; no application data is sent to a server or stored remotely.

Checks completed: JavaScript syntax, pure validation scenarios (normal, RPM over limit, nonfinite input, missing fields), deployed source readback. No actual Safari browser, touch or print QA was possible from this execution environment. All sample machining values are illustrative and unapproved.
